# Evaluation & Benchmark Protocol: Forensics Web Lab

## 1. Evaluation Philosophy & Scientific Integrity

Forensics Web Lab enforces strict empirical transparency:
1. **Zero Synthetic Metrics**: Benchmark tables and model cards must ONLY contain actual measurements generated by reproducible evaluation scripts.
2. **Mandatory Unmeasured Disclosure**: If an experiment or benchmark has not yet been executed, it must be reported explicitly as `not measured` or `not evaluated`. Under no circumstances are estimated or guessed values presented as experimental findings.
3. **Multi-Dimensional Metrics**: Accuracy alone is insufficient in digital forensics. All evaluations must report Macro F1, calibration errors, and degradation resilience.

---

## 2. Evaluation Suites & Protocol

### 2.1 Suite 1: In-Domain Multi-Generator Test
* Evaluates discrimination on test splits of generators observed during training (e.g. Stable Diffusion 1.5, DALL-E, Midjourney v4).
* Metrics: Macro F1, Balanced Accuracy, Per-Class Precision/Recall/F1, AUROC, Confusion Matrix.

### 2.2 Suite 2: Cross-Dataset Generalization Test
* Evaluates models trained on Dataset A (e.g. GenImage) on Dataset B (e.g. RealHD / SAGI-D) without fine-tuning.
* Metrics: Macro F1 drop ($\Delta \text{Macro F1}$), Transferability ratio.

### 2.3 Suite 3: Unseen-Generator Test (Zero-Shot Architecture Generalization)
* Evaluates models against completely unobserved generative families (e.g. Flow Matching architectures, unseen Diffusion versions).
* Assesses whether the model learns fundamental generative synthesis signatures or merely overfits to generator-specific high-frequency patterns.

### 2.4 Suite 4: Localization Benchmark (Inpainting Mask Recovery)
* Evaluates localized patch heatmap predictions against ground-truth binary masks from `SAGI-D` and `RealHD`.
* Metrics:
  * **Pixel-level AUROC**: Area under ROC curve over all spatial pixels.
  * **Mean Intersection over Union (mIoU)**: Evaluated at optimal calibrated threshold $\tau^*$.
  * **Dice / F1 Score**: Overlap quality between binary thresholded prediction and ground truth.
  * **Pointing Accuracy**: Fraction of samples where the maximum predicted suspicion point falls inside the true inpainting mask.

### 2.5 Suite 5: Robustness & Degradation Stress Testing
Evaluates resilience across a comprehensive matrix of realistic distortions:
* **JPEG Compression**: Standard quality factors $Q \in \{90, 70, 50\}$.
* **Spatial Resizing**: Downscaling by factors $0.75\times, 0.50\times, 0.25\times$ followed by bicubic upsampling.
* **Aspect Cropping**: Central and random crops removing $10\%$ to $40\%$ of context.
* **Screenshot Simulation**: Sub-pixel rasterization distortion and color space conversion.
* **Metadata Stripping**: Verification that removal of EXIF/XMP tags does not bias the detector.
* **Non-AI Traditional Editing (Hard Negatives)**: Testing on manual Photoshop retouching, exposure blending, and tone-mapping to measure False AI Positive Rate ($FPR_{\text{AI}}$).

## 3. Probability Calibration & Uncertainty Metrics

### 3.1 Expected Calibration Error (ECE)
Samples are partitioned into $M=10$ equally spaced confidence bins $B_m$:
$$\text{ECE} = \sum_{m=1}^M \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$

### 3.2 Brier Score
Measures mean squared error of probabilistic predictions:
$$\text{BS} = \frac{1}{N} \sum_{i=1}^N \sum_{c=1}^C (p_{ic} - y_{ic})^2$$

### 3.3 Coverage vs. Error Rate Trade-off
When the detector is permitted to output `uncertain` when confidence falls below threshold $\tau_{\text{conf}}$:
* **Coverage**: Proportion of non-uncertain predictions.
* **Selective Error Rate**: Error rate calculated exclusively over accepted (non-uncertain) samples.

## 4. Client-Side Browser Efficiency Benchmarks

Evaluated directly inside modern web browsers across WASM and WebGPU backends:
1. **Model Cold Start / Initialization Latency**: Milliseconds from model fetch to `ort.InferenceSession` ready state.
2. **Single Patch Inference Latency**: Milliseconds per $224 \times 224$ patch on CPU WASM (1 thread, multi-thread SIMD) vs WebGPU.
3. **Full Image Analysis Latency**: End-to-end wall-clock time including magic byte audit, EXIF parsing, global inference, overlapping patch grid scan ($N=24$ patches), and DSP signal extraction.
4. **Peak Memory Consumption**: Heap allocation in the Web Worker throughout a complete scan.
5. **Main Thread FPS**: Confirms 60 FPS UI responsiveness via `requestAnimationFrame` delta tracking during intensive background inference.
