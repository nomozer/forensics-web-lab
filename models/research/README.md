# Research Models Directory (`models/research/`)

> **Cảnh báo Pháp lý**: Thư mục này chỉ lưu trữ các checkpoint PyTorch / ONNX thử nghiệm được huấn luyện từ các bộ dữ liệu học thuật phi thương mại (Research Track).  
> **Quy định bất biến**:  
> 1. **Cấm tuyệt đối** việc đăng ký bất kỳ checkpoint nào tại đây vào `models/registry.json` của sản phẩm.  
> 2. **Cấm tuyệt đối** việc đóng gói các file này vào bundle của ứng dụng web (`apps/web/dist`).  
> 3. Không commit các file checkpoint nhị phân (`.pt`, `.pth`, `.onnx`) vào Git.
