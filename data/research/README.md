# Research Data Directory (`data/research/`)

> **Cảnh báo Bản quyền**: Thư mục này chỉ chứa dữ liệu phục vụ nghiên cứu khoa học học thuật (ví dụ: GenImage, SAGI-D, RAID).  
> **Nguyên tắc**:  
> 1. Mọi dữ liệu tại đây thuộc **Research Track** và mang các điều khoản phi thương mại (Non-Commercial, Share-Alike).  
> 2. Tuyệt đối **KHÔNG** sử dụng dữ liệu tại đây để huấn luyện mô hình cho bản phát hành web thương mại (`Product Track`).  
> 3. Tuyệt đối **KHÔNG** commit các tệp ảnh hoặc archive vào Git (đã được cấu hình chặn trong `.gitignore`).
